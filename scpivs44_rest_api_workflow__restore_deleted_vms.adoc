= 使用 SCV 恢复已删除虚拟机的 REST API 工作流程
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
要使用适用于 VMware vSphere 的 SnapCenter 插件 REST API 对 VM 备份执行还原操作，您必须遵循规定的 REST API 调用顺序。

对于每个REST API、添加 `\https://<server>:<port>` 在REST API的前面、形成一个完整的端点。

|===
| 步骤 | REST API | 注释 


| 1. | 转至 `\http://<vCenter-IP>/mob` | 从 VMware Managed Objects URL 中查找数据存储库 *moref*。请注意已删除虚拟机所在数据存储库的 moref。 


| 2. | `/4.1/datastores/{moref}/backups` | `Get Datastore Backups` 检索指定数据存储区的备份列表。传递步骤 1 中的 *moref*。记下要还原的备份的 *backupId*。 


| 3. | `/4.1/backups/{backupId}` | `Get Backup Details` 检索指定备份的详细信息。传递步骤 2 中的 *backupId*。在实体列表中，找到与已删除虚拟机匹配的 *entityName*，并记录 *UUID*。 


| 4. | `/4.1/vm/backups/{backupId}/snapshotlocations` | `Get snapshot locations` 检索指定备份的快照位置。传递步骤 2 中的 *backupId*。请注意 *snapshotLocationsList* 信息。 


| 5. | `/4.1/datastores/{moref}/availableEsxHosts` | `Get available ESX Hosts` 检索存储备份的主机的信息。传递步骤 1 中的 *moref*。请注意 *availableEsxHostsList* 信息。 


| 6. | `/4.1/vm/{uuid}/backups/{backupId}/restoreVm` | `Restore a VM from a backup` 还原指定的备份。传递步骤 3 中的 *UUID*。传递步骤 2 中的 *backupId*。在 *restoreLocations* 属性中，传递步骤 4 中 *snapshotLocationsList* 的信息；在 *esxHost* 属性中，传递步骤 5 中 *availableEsxHostsList* 的信息。如果虚拟机备份是部分备份，则将 `restartVM`参数设置为 *false*。*注意：* 您无法还原作为模板的虚拟机。 
|===
